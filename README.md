VOTIFY DIAMOND — Opinion Arena

Votify Diamond is a single-file Progressive Web App — open index.html in any
modern browser, or install it to your home screen for a full-screen,
offline-friendly experience.

WHAT'S INSIDE
- Back button works everywhere — opening the Radio & Sound screen (or Room
  Settings / profiles) and pressing the phone's back button now closes that
  screen instead of leaving the app. The in-screen back arrows work the same.
- Radio is polite — when the owner or DJ starts or changes a station, the
  room just hears the music. No more "Room Radio started / stopped by X"
  messages in the chat and no more "who changed the song" pop-ups. The
  now-playing chip, room menu and sound board show only the station — never
  who put it on.
- Room Radio OFF — every user gets an "OFF for me" button (and a switch)
  that turns the room radio off on THEIR device only; everyone else keeps
  hearing it. After turning it off they can play My Radio for themselves as
  they like, and stopping My Radio brings the room radio back on their
  device automatically.
- World Chatter — smart auto-scroll like WhatsApp: new messages follow while
  you are at the bottom, but if you scroll up to read, new messages NEVER
  drag you back down; scrolling back to the bottom re-follows. The emoji
  button opens a WhatsApp-style SQUARE emoji box (header + big 7-column
  grid). The online strip above the chat is one ultra-slim bar, visible on
  every screen size.
- Big smooth animations — 20 new ones: screens slide in, headers drop,
  sound-board rows cascade, the ON AIR badge glows, live dots ripple, the
  selected radio mode has a travelling gradient border, toasts spring in,
  filters shimmer, icons wiggle and more (all disabled automatically for
  reduced-motion users).
- Radio & Sound screen — the room owner and the DJ still get TWO BIG
  BUTTONS (📻 ROOM RADIO for everyone / 🎧 MY RADIO only for them) and a
  real desktop two-column layout on computers. No volume buttons anywhere —
  every device plays at full volume (uploaded room songs get a 200% boost).
- Diamond Rooms — owners, moderators, DJs, VIPs, mutes, bans, join/leave
  messages, hourly cleanup, full-screen Room Settings, Favorites, sorting,
  Jump Back In, room background music, Web Pics and quick actions
  (upload from device + camera).
- Coins-only economy, XP Shop, gifts, avatars, aura avatars, night mode,
  Whisper DMs, voice notes, mini games, battles, community feed, diary,
  leaderboards and more.

INSTALL (PWA)
- Android (Chrome): menu (⋮) → "Install app" / "Add to Home screen".
- iPhone (Safari): Share (⬆️) → "Add to Home Screen".
- Or just keep opening index.html — everything runs in the tab.

FILES
- index.html — the whole app (about 1.5 MB, no build step needed)
- manifest.json + icons — install support
- service-worker.js — offline cache
